# PT SNS homepage

Company showroom for PT SNS, Indonesia licensee of the Korean brand Joonini.

- Live (after Pages is on): https://ahnpro119.github.io/sns-homepage/
- Planned domain: https://snscorp.co.id
- Products are edited in `products.json`. No Google Sheet.

## Publish

GitHub → Settings → Pages → Branch `main` / root → Save.

Do not add a CNAME until `snscorp.co.id` DNS points at GitHub Pages.
